🔗 문제 : 프로그래머스 - 올바른 괄호
💻 언어 : Python
🏷️ 유형 : Stack / 문자열

💡 접근 방법

  • 문자열을 순회하면서 첫 문자가 ')'이면 즉시 False 반환
  • '('을 만나면 deque에 추가하고 cur_s에 '(' 기록
  • ')'을 만나면 deque가 비어있지 않고 cur_s가 '('일 때 pop으로 매칭 처리

📌 핵심 아이디어

deque를 스택처럼 사용해 '('을 쌓고 ')'가 나오면 pop으로 짝을 맞추는 방식임. cur_s로 직전 문자 상태를 확인함.

💻 코드


# https://school.programmers.co.kr/learn/courses/30/lessons/12909

from collections import *


def solution(s):
    answer = True

    queue = deque()
    cur_s = ""

    for idx, i in enumerate(list(s)):
        if (i == ")") & (idx == 0):
            return False
        elif i == "(":
            queue.append(i)
            cur_s = i
        else:
            if (len(queue) > 0) & (cur_s == "("):
                queue.pop()

    if len(queue) == 0:
        return True
    else:
        return False

⏱️ 시간 · 공간 복잡도

시간복잡도 : O(N)

  • 문자열을 한 번 순회하며 각 문자에 대해 상수 시간 연산만 수행함

공간복잡도 : O(N)

  • 최악의 경우 모든 문자가 '('이면 deque에 모두 저장되므로 추가 공간이 문자열 길이만큼 필요함

🔎 코드 리뷰

잘 적용한 부분

  • 초기 ')'를 빠르게 판별하여 불필요한 연산을 줄임
  • deque를 사용해 push/pop이 O(1)로 동작하도록 구현함
  • 최종적으로 스택이 비어있으면 올바른 괄호로 판단하는 간단한 종료 조건 사용

⚠️ 확인이 필요한 부분

빈 스택에서 닫는 괄호를 만났을 때 False를 반환하지 않음

코드가 ')'을 만났을 때 스택이 비어있으면 아무 동작도 하지 않으므로 추가적인 닫는 괄호를 무시하고 결과적으로 잘못된 문자열을 True로 반환할 수 있음

반례 예시 
())
비트 연산자 '&' 사용으로 가독성 및 잠재적 오류 가능성

조건식에서 논리 연산에 and 대신 &를 사용함. 현재는 불리언에 대해 동작하지만 가독성이 떨어지고 피연산자가 불리언이 아닐 경우 의도치 않은 동작 유발 가능함
cur_s 변수의 불필요성 및 상태 관리 혼란

cur_s는 '('을 만났을 때만 갱신하고 pop 시 갱신하지 않아 상태가 불필요하거나 오해의 소지가 있음. 스택 자체의 존재 여부만으로 판단 가능함

🔧 개선 방향

  • ')'를 처리할 때 스택이 비어있으면 즉시 False 반환하도록 수정
  • cur_s 변수를 제거하고 스택의 길이로만 매칭 판단하도록 간단화
  • 조건문에 and를 사용하여 가독성 및 안전성 개선
  • list(s) 대신 문자열 직접 순회(for c in s)로 약간의 비용 절감 가능

📝 회고

  • 괄호 매칭은 스택으로 처리하며 빈 스택에서 닫는 괄호를 바로 처리해야 함
  • 불필요한 상태 변수를 도입하면 로직을 복잡하게 만들거나 오류 유발 가능함
  • 파이썬에서 논리 연산자는 and/or를 사용하는 것이 명확함
